# WorkBuddy2API · AxManager 模块

这是将 **WorkBuddy2API** 适配封装到 AxManager、用于 Android ARM64 的模块。

## 下载

在本仓库的 [Releases](https://github.com/ngramplan/workbuddy2api-axmanager/releases) 页面下载最新模块 ZIP。首次安装需要下载 Ubuntu ARM64 基础系统并安装依赖，请预留约 2.5 GiB 空间。

## 模块功能

- 在 Android ARM64 上通过 Ubuntu PRoot 运行服务。
- 在 AxManager 中安装运行环境、启动、停止、重启服务并查看日志。
- 管理页面默认仅监听手机本机地址。

## 上游项目

本仓库发布的是 WorkBuddy2API 的 AxManager 安卓适配模块。上游开源项目：[https://github.com/ithtelab/workbuddy-manager](https://github.com/ithtelab/workbuddy-manager)。

模块所包含组件及许可证说明见压缩包内的 `THIRD_PARTY.md` 与 `runtime/licenses/`。
